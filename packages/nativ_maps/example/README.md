# Ejemplo de `nativ_maps`

`nativ_maps` es **Dart puro**: no necesita Flutter ni un emulador. Este
ejemplo se ejecuta desde la línea de órdenes.

```sh
dart run example/main.dart TU_CLAVE us-east-1
```

Para la app de Flutter completa, con las ocho pantallas que ejercitan todas las
operaciones, ver [`example/`](https://github.com/delioribas/nativ_maps/tree/main/example)
en la raíz del repositorio.
